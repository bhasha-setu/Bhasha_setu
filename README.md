# 🌉 Bhasha Setu (भाषा सेतु — The Language Bridge)

> **Connecting Script to Spontaneous Speech**  
> *A Zen-minimalist Indian voice & active-recall language learning application.*

---

## 📂 Repository Structure

* **[`bhasha-setu-frontend/`](./bhasha-setu-frontend):** Android mobile application built with React Native, TypeScript, and Expo SDK 58.
  * **100% Active Recall & Spoken Production:** 0% multiple-choice guessing buttons.
  * **6 Finalized Screen Flows:** Splash Loading, Quest Map with River Crossing Path, Bollywood Studio Lyric Recall, Cricket Commentary Roar Drill, Street Food Masterchef Counter, and Diwali Call with Nani.
  * **Custom Devanagari Virtual Keyboard:** Tactile haptic keycaps designed for mobile Hindi typing.
  * **Real-time Audio & Roar Gauge:** Dynamic decibel-driven soundwave meters and native WhatsApp milestone sharing.
* **[`bhasha-setu-AI/`](./bhasha-setu-AI):** AI backend services, speech recognition (ASR) pipelines, and conversational voice agent integrations (Bolna Voice AI).

---

## 🚀 Quick Start (Frontend)

```bash
# 1. Navigate to the frontend directory
cd bhasha-setu-frontend

# 2. Install dependencies
npm install

# 3. Start Expo development server
npx expo start
```

Press `a` in the terminal to launch on an Android emulator, or scan the QR code with **Expo Go** on an Android device.

For full technical specifications, architecture details, and component props contracts, refer to the [Frontend TRD](./bhasha-setu-frontend/docs/TRD.md) and [Frontend README](./bhasha-setu-frontend/README.md).
